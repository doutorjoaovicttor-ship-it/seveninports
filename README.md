# Seven Imports

Loja de revenda de iPhones e produtos Apple no Distrito Federal.

## Projeto

Este repositório será a base do sistema/site oficial da Seven Imports.

### Diretrizes iniciais

- Atuação: Distrito Federal (DF)
- Segmento: revenda de iPhones e produtos Apple
- Posicionamento: confiança, procedência, transparência e experiência premium
- Canais: loja/site, WhatsApp e redes sociais
- Catálogo: aparelhos novos e/ou seminovos conforme estoque e procedência
- Futuras integrações: catálogo, estoque, pedidos, clientes, pagamentos e atendimento

## Observação

A Seven Imports é uma revendedora independente. O projeto não deve sugerir que a empresa é Apple Store ou Revendedora Autorizada Apple sem que isso seja efetivamente comprovado. Informações sobre garantia e assistência devem ser apresentadas de forma precisa.

## Desenvolvimento

Todas as próximas alterações do projeto devem ser mantidas neste repositório.
